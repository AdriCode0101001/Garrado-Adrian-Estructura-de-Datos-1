### ✅ Convenciones aplicadas

Todo el código sigue los estándares definidos en la **Unidad 0** del curso:

- Nombres en `snake_case` (variables/funciones) y `PascalCase` (clases), según PEP 8
- Docstrings completos (`Args`, `Returns`, `Raises` cuando aplica) en cada clase y método
- Type hints en parámetros y valores de retorno
- Cada archivo es ejecutable de forma independiente mediante `if __name__ == "__main__":`

### ▶️ Cómo ejecutar un ejercicio

```bash
git clone https://github.com/AdriCode0101001/TU-REPOSITORIO.git
cd TU-REPOSITORIO/unidadX/ejercicios
python nombre_del_ejercicio.py
```
